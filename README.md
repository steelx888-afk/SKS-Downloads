# SKS desktop downloads

Download the Windows applications from [SKS SI](https://project0-flame.vercel.app/downloads):

- [SKS DESIGNZ — Project A](https://project0-flame.vercel.app/api/downloads/designz)
- [SKS PROZ — Project B](https://project0-flame.vercel.app/api/downloads/proz)
- [SKS LAB — Project E](https://project0-flame.vercel.app/api/downloads/lab)

Run the application's Setup.exe to install it. Electron, the local agent and core dependencies are included. Optional local AI models download when enabled; online providers require the user's configured account. CAD integrations can require the corresponding CAD application.

Automatic updates are enabled. Open **Settings → Infor** to view the current version or check for updates.

This repository hosts Windows installers, checksum files and update metadata. The application source repositories remain private. Each application has a separate update channel.

These builds are unsigned. Windows can show an unknown-publisher warning or block unsigned software under stricter application-control policies.
